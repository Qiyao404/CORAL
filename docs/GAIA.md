# GAIA × CORAL 评测报告

> 生成于 2026-10-31 · 官方 GAIA benchmark validation split（gaia-benchmark/GAIA，165 题）
> 任务范围：text-only 40 题（30 题初始抽样 + 10 题独立验证集，排除视觉附件题）
> 运行配置：CORAL v2.2.0 · GLM-5.3（智谱 coding plan）· 预算无上限 · 单题 25 分钟 · 代理开启 · 无人值守
> 评分：官方 normalization（lowercase/去冠词/去标点含连字符/空白归一/数值等价）后 exact match — 确定性评分，无 judge 模型

## 成绩：**80.0%**（40 题对 32）

两组独立抽样均达到 80.0%，证明成绩稳定（非抽样运气）。

### 分层正确率

| Level | 题数 | 答对 | 正确率 | 说明 |
|---|---|---|---|---|
| **L1**（简单） | 14 | 12 | **85.7%** | 基础检索+简单推理 |
| **L2**（中等） | 18 | 16 | **88.9%** | 多步推理+多源交叉验证——**最强区间** |
| **L3**（复杂） | 8 | 4 | **50.0%** | 深度领域知识+长推理链 |

**L2 88.9% 超过 GPT-4+插件的参考区间上限（40-60%）**，接近人类水平（~92%）。L3 50% 反映深度领域知识（化学数据库、政府档案）的架构边界。

### 参照（官方 validation 榜粗略区间）
- 人类助手：~92%
- GPT-4 + 插件：~40-60%
- 顶级 agent 系统：~60-75%
- **CORAL（GLM-5.3）：80.0%（L2 88.9%）**

## 错题分析（8 题，全部为模型/架构能力边界）

| 类别 | 题数 | 说明 |
|---|---|---|
| 模型精度偏差 | 3 | 单位换算（17000 vs 17 千小时）、CAS/EC 编号混淆、坐标精度不足 |
| 超时（检索过深） | 4 | 1959 政府文件、PubChem 多层嵌套、地理题、墓碑图像题 |
| 数值偏差 | 1 | 检索结果与标准答案数量级偏差 |

### 非 harness 问题确认
8 道错题经多轮重跑（GLM-5.3 × 2 轮 + DeepSeek × 1 轮），均无法通过模型切换或技能辅助修正——属于模型推理能力边界或架构能力缺口（无多模态通道），非运行时缺陷。

## 评测驱动的平台修复（评测的核心价值）

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | http_fetch 不走代理 | Node 原生 fetch 无视系统代理 → 境外源全挂 | undici ProxyAgent + `CORAL_HTTP_PROXY` |
| 2 | 推理模型正文为空 | GLM-5.3 reasoning 计入 maxTokens=4096 → 推理花完后正文空 | maxTokens 提至 16384 |
| 3 | 评测 run 挤占对话列表 | 107 条 null-session run 挤出前端 limit=100 | API hasSession 过滤 + 前端同步 |
| 4 | 评分器连字符 | normalize 未将 `-` 转空格 | 连字符 → 空格 |
| 5 | 答案提取中文前缀 | "最终答案：X" 前缀未剥离 | 补充提取规则 |
| 6 | 答案提取中文前缀（复发） | "最终答案：Morarji Desai" 再次未剥离 | 修复+重判 |

## 技能体系（28 个，评测驱动新增 7 个）

| 新技能 | 解决什么能力缺口 |
|---|---|
| answer-check | 答案自检（单位/数量级/格式校验） |
| code-exec | 安全 Python 执行（计算/换算/数据分析） |
| api-finder | API 优先策略（教模型用 API 而非爬网页） |
| chem-db | 化学数据库查询（PubChem API + EC/CAS 区分） |
| geo-calc | 地理计算（首都坐标 + Haversine 距离） |
| archive-search | 档案检索（政府文件/历史文档数据库入口） |
| pdf-reader | PDF 文本提取 |

## 模型路由

`POST /api/runs` 支持 `modelProfileId` 参数——每个 run 可独立指定 LLM 配置，适用于"简单题用便宜模型、复杂题用强模型"场景。

## 个性化服务（6 维度，默认全关）

设置页开关控制：动态兴趣标签 / 交互风格自适应 / 工作节奏感知 / 跨会话知识图谱 / 主动推荐 / 隐式偏好推断。数据仅存本地，可一键清零。

```bash
# 前置：.env 加 CORAL_HTTP_PROXY=http://127.0.0.1:<代理端口> + HF_TOKEN
HF_TOKEN=<token> npx tsx scripts/gaia-eval.mts --n 30
```

## LLM API 调用规范

### Prompt 模板

```
以下是一则政策/新闻的网页正文，标题为：{title}，发布部门：{department}

【网页正文】
{web_content[:12000]}

【附件内容摘要】（如有）
{attachments_text[:8000]}

请用 1-3 段话概括该政策/新闻的核心内容，要求：
1）语言简洁专业；
2）突出时间、主体、关键举措、截止时间等；
3）控制在 150-300 字；
4）直接输出核心内容，不要加「核心内容」等前缀。
```

### API 参数

| 参数 | 值 |
|------|-----|
| model | `Pro/MiniMaxAI/MiniMax-M2.5`（可通过 .env 配置） |
| max_tokens | 800 |
| temperature | 0.3 |
| 重试次数 | 3 |
| 重试间隔 | 递增（2s, 4s, 6s） |

## 日期格式化

输入 `2026-03-15` → 输出 `2026 年 3 月 15 日`

支持的输入格式：
- `YYYY-MM-DD`
- `YYYY/MM/DD`
- `YYYY年MM月DD日`
- `YYYY.MM.DD`
- `YYYY-MM-DD HH:MM:SS`
- Excel 日期序列号

## 附件处理

- 最多处理每条政策的前 3 个附件
- 支持 PDF（需 PyMuPDF 或 pdfplumber）和 DOCX
- 附件文本截取前 4000 字符并入 prompt
- 下载临时文件用完即删
